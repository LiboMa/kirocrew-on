一个 7×24 在线的研发协作空间
用你习惯的 Coding Agent 说一句话就开始

KiroCrew ON 把开发任务交给后台的多个 Agent 分工完成：规划、实现、互审、自动纠错，全程有记录。 个人、Team 与组织在同一空间里共享会话、工作流与成果；它不绑定任何工具或模型，几乎没有学习成本。

Always-On任务在服务器上持续执行，关掉电脑也不中断，随时回来查看与续作
几乎零学习成本在 Claude Code、Kiro CLI 里用自然语言操作，同一份 Skill，不必学新界面
解耦、可替换工具与模型按任务选择，Agent 可以替换；部署在你自己的 AWS 账号
What it is

它是什么

一个把“交代任务 → 多 Agent 协作完成 → 共享成果”变成日常习惯的后台空间。

⏱

后台协作空间

任务交出去后在服务器上运行；进度、证据、对话都保存在会话里。

⚙

多 Agent 编排

KiroCrew Agent 识别意图、补全需求、拆分任务、为每个任务选 Agent；Kiro、Claude Code、Codex 分工执行与互审。

⇄

共享空间

个人空间与 Team 空间；Team 成员共享会话与产出；好的工作流可共享给个人或 Team 复用。

✓

质量由平台把关

Agent 交付的交接文件与结论经平台校验才算完成；不通过时自动诊断并返工。

What it is not

它不是什么

  • 不是新的 IDE 或 Coding Agent你继续用自己的工具，KiroCrew ON 只是它们背后的协作空间。
  • 不是模型或模型网关模型由各工具与 KiroCrew 的原生配置提供（当前部署经 Amazon Bedrock）。
  • 不绑定任何工具或模型工作流里每个任务可以指定工具与模型，也可以交给 KiroCrew Agent 选择。
  • 不是 CI/CD 或自动发布不自动合并、不部署到生产；结果先供人查看与决定。
  • 不是聊天机器人对话只是入口；会话、任务、尝试、证据都有结构化记录，可追溯。
  • 不是托管 SaaS部署在你自己的云账号里；执行环境按个人 / Team 隔离。

Who it is for

个人、Team、组织

个人开发者

在自己的空间提交与迭代；查看进度、观察 Agent 对话、预览产出；沉淀自己的工作流。

Team

成员共享会话与产出；owner 管理成员；Team 可拥有专属的执行环境（独立主机），成员直接打开原生会话。

平台管理员

创建用户与 Team；开通、共享、分配执行环境；一条命令增加 Worker 主机；查看环境健康与负载。

组织 规划

组织层统一治理；会话共享给个人 / Team / 组织；配额与排队。

Architecture

架构：五层，层层解耦

平台只负责“谁、在哪个空间、做什么、做得怎么样”；怎么跑 Agent 交给 KiroCrew；用什么模型由各工具配置。

解耦

接入只依赖 Skill + MCP 这一层薄协议；调度层不运行 Agent、不绑定模型；Agent 与模型按任务选择。

单向驱动

平台经 Worker 驱动 KiroCrew；会话状态以平台为准，原生会话是执行与对话的记录。

隔离

每个执行环境是独立的系统账号或独立主机；Team 可拥有自己的 Worker 主机；原生登录只发给有权使用整个环境的人。

逐层接口、时序与信任边界见仓库 docs/ARCHITECTURE.md。

Roadmap

Roadmap

从“跑通协作闭环”到“Always-On 的组织协作空间”。以下为规划，顺序以负责人确认为准。

0.1.0 跑通协作闭环 当前

连接 → 提交 → 规划 → 多 Agent 执行与互审 → 观察 → 预览 → 续作；Team 执行环境与独立 Worker 主机。

0.2.0 可管理

用户与 Token 生命周期、管理员审计、Team 与 Worker 管理、MCP 按角色调用；私有仓库（GitHub 只读）。

0.3.0 成果出库

候选 commit 与 Feature 分支推送；在 Coding Agent 中直接读取分支与 diff；Feature 报告。

0.4.0 完成优先

瞬时重试、工具回退链、预算与看门狗、批准请求可见、命名质量门禁：先保证每个任务完成。

0.5.0 处处可用

Codex、Kiro IDE 一键接入；服务端分页与全文检索；diff 与报告视图。

1.0.0 Always-On 组织协作空间

组织层；会话共享给个人 / Team / 组织；Draft PR / MR；Issue、Webhook、定时触发；记忆按空间分层；配额与排队。

Vision

远景：7×24 Always-On 的共同协作空间

研发不再停在某个人的电脑上：需求随时交出去，Agent 一直在做，人在合适的时候查看、决定与协作。

一直在线

任务、审查、纠错在后台持续进行；需求来自一句话，也可以来自 Issue、Webhook 或定时计划。

个人 · Team · 组织

个人空间里试验，Team 空间里协作，组织层统一治理；会话、工作流、成果按需共享，权限清楚可追溯。

工作流即资产

好的研发流程沉淀为可版本化、可共享、可推荐的工作流，新任务自动套用。

不改变你的习惯

每个人用自己习惯的 Coding Agent 与 Skills 操作同一个空间；不绑定工具与模型，几乎没有学习成本。

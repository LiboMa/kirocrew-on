# 用量（D46 P6a）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 每个 Attempt 记下 Credit、token、费用与耗时，会话汇总，任务卡片、报告与 MCP 显示。

**Architecture:** Worker 在 `/inspect` 发现原生任务结束时组装 `evidence.usage`（`/api/spawn/{id}` 的 credits / elapsed，`/api/usage/turns` 中这次运行的一行），缓存到 `usage.json`；平台视图汇总 `run.usage`，`report.py`、`mcp.py`、控制台显示。

**Tech Stack:** Python 3.12 标准库、unittest；React + TypeScript + vitest。

**Spec:** `docs/superpowers/specs/2026-10-19-usage-design.md`

## Global Constraints

- usage 字段：`credits`（float）、`seconds`（float）、`turns`（int）、`input_tokens`、`output_tokens`、`cache_read_tokens`、`cache_write_tokens`（int）、`cost_usd`（float）、`model`（str）；token 不可得时 `tokens: "unavailable"`。
- slot：`subagent:` + （`continued.conversation` 或原生 ID）；行匹配窗口：`started` 至 `started + seconds + 300`，取最后一行。
- 查询失败、字段缺失或非数字：省略该字段，不报错、不改变判定。

## Review Focus

- 续接的两轮共用一个 slot：各自只取自己时间窗内的一行（Task 1 `test_continued_runs_take_their_own_row`）。
- 运行因回合上限结束没有那一行：只有 credits / seconds，标 `unavailable`（Task 1 `test_without_a_row_tokens_are_unavailable`）。
- 已有 `usage.json`：不再查询（Task 1 `test_usage_is_read_once`）。
- 旧 Attempt 没有 usage：汇总时跳过，不出错（Task 2 `test_older_attempts_without_usage_are_skipped`）。
- 非数字或负数：忽略（Task 1 `test_odd_values_are_dropped`）。

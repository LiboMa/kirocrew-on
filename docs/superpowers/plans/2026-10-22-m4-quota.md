# M4-4 第 2 期：每人 / 每 Team 的并发上限 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 管理员与 Team owner 可设同时运行的任务数上限；到了上限，会话的新任务按等待先后排队，有空位自动开始。

**Architecture:** 迁移 10 的 `quotas` 表；`octopus/quotas.py` 算有效上限、占用、谁先；引擎在为会话创建下一个 Attempt 的写事务里判定，
满了就记 `quota_wait`（会话快照）与事件，不创建 Attempt；有空位且没有更早等待的就开始并记 `run.quota_go`。

**Tech Stack:** Python 3.12 标准库、SQLite；React + TanStack Query（控制台）。

**Spec:** `docs/superpowers/specs/2026-10-22-m4-quota-design.md`（D61）

## Global Constraints

- 没有设的范围不限制：无任何 `quotas` 行时，引擎行为与今天逐字节相同（同样的事件、同样的派发次数）。
- 上限取值 1–50 的整数；`null` 取消。
- 权限：`default` 与 `user` 只有平台管理员（`elevated`）；`team` 为该 Team 的 owner 或平台管理员；每次修改写审计 `quota.set`。
- 使用者看到的文字：「排队：已达到并发上限（你同时运行的任务已达 N 个，上限 N）」或「排队：已达到并发上限（Team「X」同时运行的任务已达 N 个，上限 N）」。
- 不改 D57（另一会话）的门禁与纠错语义；迁移号 10 先通知 D57 会话。

## Review Focus

- **两个会话同时在 tick 中抢一个空位**：同一写事务内判定并创建 Attempt，只有一个开始（Task 2 测试：上限 1、两个就绪会话、一次 tick）。
- **执行环境停用留下的 `running` Attempt**（会话 `blocked`）：不占位（Task 1 测试）。
- **等待的会话被停止**：不再占队首，后面的会话照常开始（Task 2 测试）。
- **上限调小到低于当前占用**：运行中的不受影响，新任务等待（Task 2 测试）。
- **Team 会话**：同时受个人与 Team 两个范围约束，提示写明是哪一个（Task 2 测试）。

### Task 1: 上限的存储、占用与接口

**Files:** Create `octopus/quotas.py`；Modify `octopus/migrations.py`（迁移 10）、`octopus/domain.py`（`quotas`、`set_quota`）、
`octopus/server.py`（`GET` / `PUT /v1/quotas`）；Test `tests/test_quotas.py`

**Interfaces — Produces:**
- `quotas.limits(db, owner_id, team_id) -> {"user": int | None, "team": int | None}`（个人：单独上限，否则每人默认）
- `quotas.usage(db, *, owner_id=None, team_id=None) -> int`（Attempt 与 recoveries 在 `dispatching/running/waiting_approval/dispatch_unknown`，会话仍在推进）
- `quotas.full(db, run) -> dict | None`：`{"scope": "user"|"team", "limit", "used", "team_name"?}`，先看个人再看 Team
- `Service.quotas(actor) -> {"mine": {"limit", "used"}, "teams": [{"id", "name", "limit", "used", "manage"}], "default"?: int|None, "users"?: [{"id", "name", "limit"}]}`（`default`、`users` 只给管理员）
- `Service.set_quota(actor, body) -> 同 quotas(actor)`；body `{"scope", "id"?, "running"}`

- [ ] 测试：迁移 10 建表；`limits` 的单独上限优先于默认；`usage` 数个人（含 Team 会话）与 Team；`blocked` 会话里留下的 `running` Attempt 不计；诊断计入；
  `PUT` 权限（成员 403、Team owner 可设本 Team、管理员可设 default / user）、取值 0 与 51 被拒、`null` 删除；审计 `quota.set`；`GET` 非管理员看不到 `default` 与 `users`。
- [ ] 失败；实现；通过（含 `tests.test_migrations tests.test_access`）；提交。

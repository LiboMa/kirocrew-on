# 管理与「我的设置」：用对话框完成操作（UI PRD）

状态：负责人 2026-10-23 确认第 7 节三点（范围与规则、单字段设置也用对话框、先做 Token 一页看效果）；2026-10-24 看过 Token 页后同意推到其他页面，并要求 Token 增加「重新生成」、整站按「青岩」改版（见 docs/design/2026-10-24-redesign-options.html 方案一，标志用方案三的四格 K）。列表页改为表格：工具栏（搜索、刷新、数量）、表头、行内「图标 + 文字」操作；手机上行操作仍全部收进「⋯」（§3.5）。

负责人原话（2026-10-23）：「对于新增用户、新增 Worker，新增加 Token，修改 Team 相关的内容，也就是管理及我的设置的操作，多用动画，
多用对话窗口和弹窗；少用镶嵌在页面中的 checkbox 和 Input，这样在一级页面，弹窗解决问题，比直接操作 INPUT BAR，体验要好很多。」

## 1. 目标

- **一级页面只放列表和状态。** 每个页面的结构是：标题、一句说明、右上角一个主操作按钮，下面是列表；每一行的次要操作收进行尾的「⋯」菜单。页面里不再有内嵌的编辑表单。
- **新增、修改、危险操作一律在对话框里完成。** 一个对话框只做一件事，做完关闭，结果用提示条和列表里的高亮告诉用户。
- **用动画表达变化**：打开与关闭、新增与删除、成功与失败。不做装饰性的动画。

## 2. 现状与改法

以下是 2026-10-23 控制台的现状：这些面板全部把表单直接嵌在页面里，没有用对话框。

| 页面 | 现在嵌在页面里的 | 改成 |
|---|---|---|
| 管理 › 用户 | 新建用户表单（用户名、初始密码、个人空间的执行环境）；每行展开的重设密码（两个密码框） | 右上「新建用户」→ 对话框；行菜单「重设密码」→ 对话框；停用 / 启用、设为管理员 / 取消 → 确认对话框 |
| 管理 › 执行环境 | 登记 Worker 表单（名称、绑定空间、URL、Token）；每行的改名、更换 URL、更换 Token；「分配到」选择框 | 右上「登记 Worker」→ 对话框；行菜单「编辑」（名称、URL、Token）、「分配到空间」→ 对话框；退役、停用 → 确认对话框 |
| 我的设置 › Token | 新建 Token 表单（名称、权限、有效期） | 右上「新建 Token」→ 对话框。创建成功后，同一个对话框切到第二屏，只显示一次 Token，带「复制」与「我已保存」；撤销 → 确认对话框 |
| 我的设置 › Team | Team 选择、新建 Team（名称、owner、执行环境）、改名、添加成员（用户、角色） | 右上「新建 Team」→ 对话框；Team 卡片菜单「改名」「添加成员」→ 对话框；成员行菜单「改角色」→ 对话框、「移出」→ 确认对话框；归档 → 确认对话框。Team 切换保留为页面顶部的选择器，它是导航，不是编辑 |
| 我的设置 › 仓库凭证 | 新建凭证表单（名称、类型、主机、归属、仓库范围、权限、Token）；每行的仓库范围、更换 Token | 右上「添加凭证」→ 对话框；行菜单「仓库范围」「更换 Token」→ 对话框；删除 → 确认对话框 |
| 我的设置 › 映射偏好 | 新增规则表单（作用域、对应、类别或角色、工具、模型） | 右上「新增规则」→ 对话框；行菜单「编辑」「删除」 |
| 我的设置 › 并发上限 | 数字输入框 | 显示当前值，旁边「修改」→ 对话框 |
| 我的设置 › 密码 | 修改密码表单 | 「修改密码」按钮 → 对话框 |

搜索框与筛选器留在页面上：它们用来找东西，不是编辑。

## 3. 交互规则

1. **对话框**
   - 标题用动词，例如「新建用户」。提交按钮写出结果，例如「创建用户」；成功的提示条用同一个词，例如「已创建用户 alice」。
   - 打开时，焦点落在第一个输入框；Enter 提交、Esc 取消；关闭后，焦点回到打开它的按钮。
   - 失败时，对话框不关闭，在框内显示服务器给的原因（`FormDialog` 已有）；提交中不能关闭。
   - 字段多的分成小节，例如仓库凭证分「是什么」「能访问哪些仓库」「Token」，不做多步向导。
2. **危险操作**：停用、删除、撤销、退役、移出成员、归档。
   - 用确认对话框写清后果，例如「停用后，alice 立即不能登录，全部 Token 失效；进行中的会话照常执行，但不能再用 alice 的个人仓库凭证」（以服务器实际行为为准）；
   - 不可撤回的操作，要求输入名称确认，沿用会话删除的做法。
3. **一次性秘密**：新 Token、Worker Token。
   - 只在创建成功的那一屏显示一次，带「复制」按钮，复制后按钮变为「已复制」；
   - 点「我已保存」后关闭，之后不再显示。
4. **动画**：克制，只用来表达状态的变化。

   | 时刻 | 动画 |
   |---|---|
   | 对话框打开 / 关闭 | 淡入并轻微放大 / 反向（已有） |
   | 新增成功 | 对话框关闭；新行出现在列表里，背景高亮约 1.2 秒后淡去；右上角提示条 |
   | 删除、移出、撤销 | 行淡出并收起高度（约 200 毫秒） |
   | 修改成功 | 被改的行高亮一次 |
   | 「⋯」菜单 | 展开时淡入并缩放（已有） |
   | 失败 | 对话框里的错误行淡入；对话框不晃动 |

   系统设置为「减少动态效果」时，全部动画改为无动画的即时切换。
5. **移动端（390 像素宽）**：对话框占满宽度，底部按钮固定；每行只显示「⋯」，不并排放多个按钮。

## 4. 不在范围

- 会话页、启动向导、工作流编辑器：它们已经用对话框或向导。
- 后端接口：不改，只改控制台的呈现。

## 5. 验收标准

- 管理与「我的设置」各页上，没有内嵌的编辑输入框、勾选框或选择框（搜索、筛选与 Team 切换除外）；
- 每个新增、修改、危险操作，都通过主按钮或行菜单打开对话框完成；
- 新增成功：对话框关闭、出现提示条、新行高亮；失败：对话框内显示原因、不关闭；
- 一次性 Token 只显示一次；
- 「减少动态效果」下没有动画；
- 控制台单元测试与浏览器测试同步更新并通过；1280 像素与 390 像素下逐页截图检查。

## 6. 实施方式（我的建议）

- 复用现有部件：
  - 表单：`FormDialog`；
  - 行菜单：`DropdownMenu`；
  - 提示条：sonner；
  - 动画：tw-animate。
- 新增一个小部件，负责新行与修改行的高亮、删除行的收起，并在「减少动态效果」时关闭动画。
- 顺序：先做「我的设置 › Token」一页给负责人看效果，确认后再铺开到用户 → 执行环境 → Team → 仓库凭证 → 映射偏好、并发上限、密码。每页改完都更新测试。
